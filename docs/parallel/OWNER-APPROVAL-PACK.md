# Owner activation checklist and approval pack (v2, single document)

Date: 2026-11-24 · Version 2 (Master) · Integration branch `integration/ai-engine`. **Every row is UNDECIDED. Nothing here is an approval, an agreement, a legal opinion, a security attestation or a regional guarantee.** A row is ticked only with a reference (signed document id, ticket, dated message) recorded in §6. No credential is requested in this document: keys are typed by an authorized administrator into the admin console and only vault references are stored.

**How to use it.** §1 says in which order the answers unlock work. §2 is the table (one row per decision, the eight fields you asked for). §3 lists what is **not** a decision. §4 maps identifiers to their source records. Costs are hard maxima at the public list prices read on 2026-11-24 (not quotes); where no price could be sourced the cell says so, and nothing is invented. Detail behind each row: `docs/parallel/sessions/PHASE2-02/03/04/06-approval-inputs.md`, `LIVE-PROVIDER-PLAN.md`, `RUNTIME-QUALIFICATION.md`, `STAGING-DEPLOYMENT-PLAN.md`.

**"Blocks"** uses three levels: **DEV** = engineering cannot proceed (no row blocks development: everything below is built and tested offline with mocks); **STAGING** = the real staging verification track cannot start (synthetic data only); **PRODUCTION** = customer-facing activation.

## 1. Order that unlocks the most
1. **Provider path, one sitting:** D2 → D5 → D6 → D4 → D3 → D9 → first real-provider verification (tracks A–C) for at most **USD 0.314960** all-in (0.234240 if the redundant probe run is skipped).
2. **Benchmark gate (no vendor cost to decide):** AC-AG-10 thresholds, REV reviewers, SEC-AG reviewer, BUD-A ($4.40 max) → Stage A.
3. **Authorization policies O-1, O-2, O-9:** independent of everything else; implemented as switches whose default is today's behaviour.
4. **Execution:** D-21 + HG-10-02 + ADR acceptance (LEGAL-EXEC for any customer) → a dedicated Linux node → staging runtime qualification (track D, E).
5. **Deployment:** HG-05, HG-06, **HOST-TRANSPORT** → staging deployment of a synthetic app (tracks F, G).
6. **D-AG-ROLLOUT last.** D1 only when customer content may reach a model.

## 3. What is not a decision

Findings and defects (15, all fixed and re-tested) are not owner decisions.
