## Spec/prompt conflicts found (CLAUDE.md §2: higher source wins, recorded)
- **Migration range:** brief says 700–799; `spec/db/ownership.yaml` reserves **0800–0899** for M06 (and 0600–0799 for M05). Manifest wins.
- **Error code `quota_exceeded`:** docs/04 says `429`; the registry says `422` (M02) → kept 422.
- **ADR-017 name collision:** see A-13.
- **Doc 04 has no endpoints** for node enrolment tokens, inventory run, command log, agent list, per-site admin listing/suspension (PA-14 proposes `PATCH /v1/admin/hosting/sites/{id}`): added as spec additions; need owner approval.
