## Conflicts recorded (follow the higher source, no silent reconcile)
1. **Migration number 1700** is `identity.credentials` (owner's customer sign-in work, ADR-008). M12's range is 1700-1799; M12 starts at **1710** (1710 identity SSO/SCIM, 1720 audit access reviews, 1730 compliance policy versions, 1740 ops, 1750 cloud TR subjects).
2. **`cloud.resource_reconciliations` is "the only store" for TR-xx** (docs/05 §7) but M05 created it with `resource_id NOT NULL` referencing `cloud.resources` (compute only). Migration 1750 extends it (optional `resource_id`, `tr_type`, `subject_kind`, `subject_ref`, `evidence_mode`). **Manifest items for the owner:** `cloud` extended by M12.
3. **Tables added beyond docs/05's M12 list** (manifest items): `identity.sso_domain_proofs`, `identity.sso_assertion_replays`, `identity.scim_identities`, `ops.probe_runs`.
4. **Audit action names**: the prompt lists `incident.opened`, `access_review.decision`, `recovery_exercise.recorded`, `launch_gate.decided`; the audit table requires `<domain>.<resource>.<action>` (three parts). Implemented as `ops.incident.opened|updated|closed`, `audit.access_review.created|decision`, `ops.recovery_exercise.recorded`, `ops.alert.*`; `launch_gate.decided` is not emitted because no endpoint records decisions (SCR-M12-03).
5. **ETag mismatch status**: the prompt table says 409 for `PUT /v1/admin/policy-versions`; the platform registry's `etag_mismatch` is 412 and is used.
6. **Permission names**: the prompt uses `admin:security`, `admin:ops`, `admin:finance`, `admin:cloud`; the repository's platform permissions are `admin:security:manage`, `admin:compliance:read|manage`, `admin:audit:read`, `admin:billing:manage`; M12 adds `admin:ops:read` and `admin:ops:manage` (migration 1740).
7. **Policy approval**: `compliance.policy_versions.approved_by` is a human platform user different from the publisher; the agent never approves.
